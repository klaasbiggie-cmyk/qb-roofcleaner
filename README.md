# qb-roofcleaner

Een solo Dak- & Zonnepanelen Reiniger job voor FiveM QB-Core servers.

## Features
- Werkt zonder NPC's (start via commando `/startdakwerk`)
- Dynamische locaties op de kaart
- Progressbar en animatie bij het schoonmaken
- Directe bankuitbetaling per gereinigd dak

## Installatie
1. Plaats de map `qb-roofcleaner` in je `resources/[jobs]` map.
2. Voeg `ensure qb-roofcleaner` toe aan je `server.cfg`.
3. Voeg de job `roof_cleaner` toe aan je `qb-core/shared/jobs.lua`.
